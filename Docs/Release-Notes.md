SnowPlay 2.0 — native macOS preview

Minimal AppKit/SpriteKit winter system with a custom particle/surface engine, conservative CG/AX window observation, tiny layered decorations, menu bar controls and a secured loopback control panel.

Includes complete Swift sources, original SVG/transparent PNG assets, presets, unit/security tests, native fixture, manual acceptance checklist and reproducible application packaging.

This is a preview build. Native window/Dock behaviour across Spaces, Mission Control, Stage Manager, fullscreen and multiple displays requires manual acceptance. Developer ID/notarization and long-duration GPU/performance qualification are not included in the local ad-hoc build. Read Docs/Feasibility.md and Docs/Performance.md before distribution.
