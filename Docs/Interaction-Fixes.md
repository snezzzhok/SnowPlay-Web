# SnowPlay — исправления по ручной проверке

Пользователь сообщил о слабом снеге на 100%, отсутствии накопления на Dock/шапочек/лепки, невозможности двигать украшения, гирлянде на рабочем столе и ненадёжном открытии подарка.

## Причины и изменения

- Старые 100% ограничивались 100 частицами и уменьшались до 70 на батарее. Новый диапазон: примерно 200 при 35% и 1000 при 100% на 1440×900, с отдельным тихим Focus. На батарее уменьшается частота, количество сохраняется. Старый стандартный лимит 100 мигрирует в новый бюджет 1200; жёсткий предел пула 1600. Увеличены видимость и скорость достижения Dock, масса осаждения; частицы остались компактными 1–3 pt.
- Реальный Dock оказался в автоскрытии: AXList находился ниже экрана (y=900 на экране высотой 900). Прежняя проверка исключала его. Теперь скрытый Dock сохраняет физическую поверхность по публичной AX-геометрии; снег накапливается без исчезновения падающих частиц перед невидимым Dock. Рисование включается вместе с видимым Dock. Обычные окна позади Dock больше не блокируют его столкновения/снежный слой.
- Шапочки и снежный слой рисовались ниже системного уровня Dock. Canvas теперь click-through над Dock; панель выбора иконки поднимается выше только в явном режиме выбора. Без доверенной геометрии иконки не угадываются. При необходимости приложение запрашивает Универсальный доступ; отдельного разрешения на рисование/накопление нет.
- Добавлена локальная кисть курсора над снежным слоем: убирает только ближайшие отсчёты профиля, ограниченно выпускает снятый снег частицами. Глобальный перехват мыши не добавлен.
- Ёлка больше не появляется автоматически в первом свободном углу до выбора позиции. Ёлка, подарок и готовый снеговик принимают обычное перетаскивание за сам объект; позиция ёлки сохраняется. При перемещении снеговика не запускается заново сборка. Рабочая область — свободный рабочий стол, обычные окна защищены от перекрытия.
- Снежки можно катать над Dock даже при обычном окне позади него: этот небольшой участок использует прежний foreground canvas и отдельные изображения шаров; на свободном рабочем столе продолжается существующая составная сборка. Объём берётся из настоящего запаса снега. Невидимая сборка под рабочим окном запрещена; шары надо перенести на свободный участок.
- Гирлянда требует выбора конкретного окна: один клик по подсвеченной верхней полосе, затем привязка к ID окна. Удалён fallback на края рабочего стола. Провод и лампочки рисуются в существующем canvas у верхней границы выбранного окна, с обходом кнопок и окон, расположенных выше. В ключ обновления добавлен ID привязки.
- У InputView включён `acceptsFirstMouse`; панели не скрываются при деактивации приложения. Подарок открывается одним кликом после посадки, даже если Санта ещё не закончил полёт. Перетаскивание отличает движение от клика. Области ввода пересоздаются сразу при посадке/появлении объекта, без прежней задержки до 0,5 с.

Панель и 19 ручных проверок обновлены под одно нажатие на подарок и выбор верхней полосы окна. При автоскрытии или ожидании снега для первого шара показывается понятная подсказка. Прежние пользовательские отметки не стираются.

## Проверки

- 31 метод тестов через локальный адаптер того же XCTest source, 0 ошибок. Новые случаи: полный диапазон плотности, накопление Dock поверх обычных окон и при автоскрытии, локальное смахивание с учётом массы.
- Нативный контроллер с собственным внешним NSWindow fixture: ручной выбор позиции/перетаскивание ёлки с сохранением, привязка гирлянды к определённому окну, открытие подарка через первый mouseDown/mouseUp, перемещение подарка/снеговика, рост шара из запаса снега, кисть и уровни относительно Dock. Для контроллеров используется изолированная геометрия тестового окна и явно заполненная физическая unit-fixture; системные клики по чужим приложениям не инъецировались. Результат: `interaction-fixes-result.json`.
- Отдельный реальный запуск release: **1000 частиц**, за 10 с получено **2481 условная единица** настоящего накопления на скрытом Dock, без тестового заполнения. CPU в этом максимальном режиме — около **32% одного ядра**, RSS максимум около **60 MiB**. Это режим максимального снега, не прежний лёгкий профиль; GPU не измерен. Сырые отсчёты: `live-snow-fixes-result.json`.
- Проверены прежние библиотечные композиции, прозрачная отрисовка, HTTP/настройки/защита, WebKit-пульт и сохранение после перезапуска. Release `.app`/ZIP пересобран, ad-hoc подпись проверена.

Повторная ручная проверка на рабочем столе всё ещё нужна: автоматические проверки контроллеров не заменяют пользовательский клик, перетаскивание и видимость Dock в его конфигурации. Mission Control/Spaces/Stage Manager и длительные утечки по-прежнему отдельные пункты.

## Повторить проверку

1. Уменьшить/свернуть браузер, поставить снег 100%. Должна быть явно плотная метель.
2. Подвести курсор к краю экрана для появления Dock; подождать 10–20 с. Проверить слой, затем провести курсором по снегу.
3. Поставить ёлку на свободный рабочий стол и перетащить за неё. Вызвать подарок, открыть одним кликом сразу после посадки; затем перетащить коробку.
4. Выбрать гирлянду и нажать подсвеченную верхнюю полосу именно нужного окна. Передвинуть/свернуть это окно.
5. Выбрать цвет шапочки, показать Dock, нажать нужную иконку.
6. После накопления включить лепку, катать шары над Dock, затем перенести три шара на свободный рабочий стол и собрать снеговика. Готовый снеговик тоже перетаскивается.

Скрипты: `Scripts/test-core.sh`, `Scripts/test-renderer.sh`, `Scripts/test-assets.sh`, `Scripts/test-interactions.sh`, `python3 Scripts/test-snow-live.py`, `python3 Scripts/test-local-api.py`, `python3 Scripts/test-web-panel.py`. Все изменяющие проверки работают с отдельными настройками, а не с пользовательскими ручными отметками.
