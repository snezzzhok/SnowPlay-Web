# Маленькая стенка Йети

Большой замок заменён на два обычных снежных комка, стоящих рядом: каждый диаметром 11 pt, общая ширина около 20 pt. Используется существующий `snowball_medium`; PNG замка больше не загружается для этой сценки и сохранён только как архивный ресурс.

Йети ставит комки по очереди: первый подкатывается и оседает, затем второй. Постройка занимает 1,4 секунды; после завершения Йети уходит. На стенку расходуется масса двух кругов радиусом 5,5 pt (около 190 условных единиц), вместо прежнего большого запаса замка. Вероятность выбора игры — 50/50 между стенкой и броском снежка. Прежние внутренние имена `castle` сохранены для совместимости API.

Изменены `FloorDecorations.swift`, `CharacterDecorations.swift`, время действия в `WinterWorld.swift`, подписи пульта и диагностика. Предыдущая запись большого замка в отчёте нижнего мира относится к прошлой версии.

Проверка: `Scripts/TinyWallCheck.swift` запускает настоящие контроллеры в изолированной нативной сцене, проверяет последовательное появление двух комков, маленький размер, расход снега и уход Йети. Превью: [tiny-wall-preview.png](tiny-wall-preview.png); машинный результат: [tiny-wall-result.json](tiny-wall-result.json).

Результаты: 58 методов логики — 0 ошибок; нативная проверка двух комков — PASS; release `.app` и ZIP пересобраны, подписаны ad-hoc, программа перезапущена.
