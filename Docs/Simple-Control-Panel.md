# Простой пульт SnowPlay и ручная приёмка

Главный экран на русском: три действия (Санта, ёлка, снегоуборщик), количество, скорость, направление. Направление управляется перетаскиванием стрелки по полукругу на объёмной схеме; диапазон −90…+90°. Можно использовать ←/→, Shift для большего шага и 0 для прямого падения. Это управление существующим двумерным снегом, с визуальной объёмной схемой.

Гирлянда, лепка снеговика, три цвета шапочек Dock, иней, режимы и прочие параметры скрыты в «Ещё эффекты и настройки». Постоянно анимированное браузерное превью удалено. Действия используют прежние API и состояния нативного приложения; локальная панель не создаёт собственные эффекты рабочего стола.

На той же странице 19 ручных тестов с действием, ожидаемым результатом и заметкой. «Работает» переходит к следующему, «Есть проблема» сохраняет результат и оставляет текущий пункт. Можно вернуться, пропустить и скачать текстовый отчёт. Отметки сохраняются в соседнем с настройками файле `*.checks.json`, независимо от смены порта панели. Сброс украшений их не удаляет. Полный список: [Manual-Testing.md](Manual-Testing.md).

Изменены Web/index.html, app.js, style.css; добавлен testing.js. В SnowCore добавлена ManualChecks.swift; Coordinator подключает GET/POST /api/checks, отдачу testing.js и небольшую сводку текущей доставки/ограничения движения. Существующая защита Origin/Host/токен остаётся. Все ручные результаты из автоматической проверки записываются только во временные отдельные настройки.

Проверено:

- 28 тестовых методов через локальный assertion-адаптер, 0 ошибок, включая сохранение ручных результатов и отбрасывание некорректных записей.
- Реальные HTTP-запросы к приложению: ресурсы, настройки, состояния, ручные результаты, запрет записи без токена и некорректных запросов.
- Настоящий WebKit: три главных действия, закрытые дополнительные параметры, каталог, преобразование координат указателя для −90/0/+90°, направление с клавиатуры, ползунки и сохранение в нативном приложении, Pause/Resume, шаг проверки и заметка.
- Перезапуск приложения с отдельным файлом настроек: параметры, отметки и текущий пункт восстановлены на новом порту. Результат: `simple-panel-check-result.json`.
- Нативный снимок только собственной веб-страницы: `control-panel-preview.png`. JS syntax check, release-сборка, ad-hoc подпись и упаковка.

Это проверка соединения и интерфейса. Ручные сценарии рабочего стола из списка не отмечались автоматически: их проверяет пользователь. Прежние ограничения GPU/Spaces/Mission Control и длительного soak остаются в отчёте интеграции.
