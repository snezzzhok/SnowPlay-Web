# SnowPlay — маленькая зима

[Открыть сцену](https://snezzzhok.github.io/SnowPlay-Web/)

Снег, Санта, снегоуборщик, ёлка и снеговик прямо в браузере. Без установки и без входа в GitHub. Это самостоятельная браузерная сцена; демонстрационное окно находится внутри страницы. Телефон управляет своей вкладкой, синхронизации с другим экраном нет.

По умолчанию: умеренный снег (35%), скорость 1×, чистое окно. Настройки сохраняются в этом браузере. Кнопка «Сбросить настройки» восстанавливает исходную сцену.

## Запуск локально

```sh
python3 -m http.server 8080
```

Открыть http://localhost:8080/. Для тестов нужен Node.js: `npm test`; установка зависимостей не требуется.

## Проверить по одному

1. Открыть в приватном окне: видны картинки, ёлка, снеговик и снег. Демонстрационное окно чистое.
2. Изменить количество и скорость. Перезагрузить: картинки и настройки сохраняются. После завершения падения ёлки сразу перезагрузить — она не возвращается. Сбросить настройки.
3. Вызвать Санту и снегоуборщик подряд. Они движутся одновременно и заканчивают сценки.
4. Нажать «Срубить ёлку» несколько раз. Одно падение. Поставить новую.
5. Нажать «Бросить снежок в снеговика» несколько раз. Один снежок, дуга, разрушение. Слепить нового.
6. Открыть подарок одним нажатием: три цвета салюта, отсчёт, коробка исчезает.
7. Включить снег на окошке, дождаться накопления и потянуть за заголовок: снег падает вниз.
8. На телефоне проверить доступность кнопок и отсутствие горизонтальной прокрутки.

## FPS на своём устройстве

Открыть «Проверка плавности», указать модель устройства и браузер, нажать «Начать замер». Оставаться во вкладке 26 секунд: 2 секунды прогрева и 24 секунды одновременного снегопада, полёта Санты и уборки. Скачать JSON. Для исходного способа рисования открыть сцену с `?renderer=baseline` и повторить замер на том же устройстве.

Измеряются интервалы requestAnimationFrame и CPU-время симуляции/отрисовки, а не время GPU. Скрытие вкладки делает замер недействительным. Результат зависит от браузера, экрана и режима энергосбережения. Проверка мобильной вёрстки на компьютере не заменяет измерение на настоящем телефоне.

## Графика и устройство

SVG из предоставленной библиотеки SnowPlay сохранены; `assets/manifest.json` содержит 23 идентификатора, относительные пути и SHA-256. Ресурсы загружаются один раз и подготавливаются до первого кадра. Нет внешних CDN, шрифтов, API или сервера приложений. HTML, CSS и ES-модули можно размещать в подпапке GitHub Pages.

Один цикл анимации; отдельные состояния Санты и машины; ограниченное число частиц и подарков; пауза скрытой вкладки; повторные действия не дублируют анимации.

## Проверенный результат на компьютере

Реальный Mac Apple M1, гостевой Chrome, публичная страница, энергосбережение macOS включено. Сцена 810×661 CSS px при DPR 2, максимум 1460 снежинок, 24 секунды после прогрева. Одновременно снег, Санта и снегоуборщик.

| Метрика | Исходный рендер | Итоговый |
|---|---:|---:|
| FPS | 60 | 60 |
| p95 интервала кадра | 17,6 мс | 17,6 мс |
| Максимальный интервал | 17,8 мс | 17,8 мс |
| Интервалы >25 мс | 0 | 0 |
| Среднее CPU-время шага и отрисовки | 1,624 мс | 1,371 мс |
| p95 CPU-времени | 1,9 мс | 1,7 мс |

Выгрузки из интерфейса: [до](checks/chrome-baseline.json), [после](checks/chrome-final.json). Это короткий прогон одного устройства и браузера, не универсальная гарантия. На том же Mac отдельный WebKit-fixture с энергосбережением показал 30 FPS. Настоящий телефон не тестировался; мобильная вёрстка проверена на ширине 390 px на компьютере. Вкладка сама не может подтвердить тип физического устройства, поэтому поле `physicalDeviceVerified` в её JSON остаётся false; факт Mac/Chrome проверен при ручном запуске.

Готовность сцены включает декодирование превью в пульте. Завершённое падение ёлки сохраняется в тот же кадр, без отложенной записи.

Контроль опубликованного релиза после исправлений перезагрузки и кеша: [chrome-release-check.json](checks/chrome-release-check.json). Снова 60 FPS под совместной нагрузкой. Скрипты и изображения имеют ключи версии, поэтому после обновления Pages не смешиваются модули разных версий.
